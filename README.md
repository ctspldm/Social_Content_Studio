# Social Content Studio

A one-file app that turns a short brief into a ready-to-post **Instagram/Facebook Reel and Story package** for Meta Business Suite. It writes the text with Claude and makes the videos right in your browser.

It's set up for **Natania Preschool**, **New Genesis Educational Institution (NGEI)** and **CentureTech Solutions**, and you can add more brands in Settings.

**▶ Open the app:** https://ctspldm.github.io/Social_Content_Studio/ (use Microsoft Edge or Google Chrome)

## What you get for every post

| | |
|---|---|
| 🎬 Reel video | 1080×1920 MP4 with animated scenes and original background music |
| 🖼 Reel cover | Thumbnail image with your search keyword |
| 📱 Stories | Each frame as a 6-second MP4 **and** a PNG |
| 📝 Text | Instagram caption + hashtags, Facebook caption, first comment, location tag, hook, shoot script, alt text, sticker instructions, posting tips |
| 📤 Upload helper | Every reel and story in posting order, with copy buttons and a tick box for each |
| ⬇ Export | ZIP with one folder per post, plus `upload-sheet.csv` |

## How to use

1. Open **https://ctspldm.github.io/Social_Content_Studio/** in **Microsoft Edge or Google Chrome**, the browsers that can make the videos. Bookmark it.
   (Or download `index.html` and double-click it.)
2. Click **⚙ Settings**, paste your Claude API key (from [console.anthropic.com](https://console.anthropic.com) → API Keys), then click **Save**.
   You can also upload each brand's logo there and edit its colours, music, contact details, hashtags and rules.
3. On **✏️ Create**, pick a brand, type or paste the brief, then click **Create**.
   - **＋ Add another post** adds more posts, for any brand.
   - **📋 Paste many briefs (bulk)** lets you paste many at once, with a `---` line between them.
   - Optional photos you add to a post appear in the video.
4. Open **📚 Library** to watch the videos, copy texts, edit the video text and re-make it, or rewrite with Claude.
5. Use **📤 Upload helper** or **⬇ Download all (ZIP)** to publish through Meta Business Suite.

There is nothing to install. You need an internet connection to reach Claude and to load fonts and the libraries.
Everything you make (settings, posts, videos) is saved in your own browser.

## How it works

- **Text:** Claude (`claude-opus-5-5`) returns structured JSON that holds the captions, the stories and a scene-by-scene video plan.
- **Video:** the plan is drawn on an HTML canvas. The browser's built-in video encoder (WebCodecs) and [mp4-muxer](https://github.com/Vanilagy/mp4-muxer) turn it into an MP4.
- **Music:** generated by the app itself (ukulele/glockenspiel, piano or corporate style), so it's royalty-free.
- **Storage:** settings and texts in `localStorage`, videos and photos in IndexedDB. The ZIP is built with [JSZip](https://stuk.github.io/jszip/).

## Notes

- The phone mock-ups in the videos are illustrations. Check that the sample items match your real app before posting.
- Your API key is stored only in your browser and is sent only to Anthropic's API.
